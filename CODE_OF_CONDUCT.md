# Code of Conduct

Genealogy Capsule follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, assume good faith, and keep criticism about the work. Harassment,
personal attacks and publishing anyone's private information are not tolerated. Family history
is personal; treat other people's ancestors and research with the same care as your own.

This applies in the issues, discussions and pull requests of this repository.

## Reporting

To report a problem privately, use **Security → Report a vulnerability** on this repository
and say it is a conduct report; that form reaches only the maintainer. Reports are kept
confidential. The maintainer may remove comments, lock threads or block accounts that break this
code, following the Covenant's enforcement guidelines.
