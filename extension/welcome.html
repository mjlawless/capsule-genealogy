About the warnings Chrome showed you

      

        Chrome describes every extension's permissions in its own broad, standard words, not
        the developer's. Here is what each one means for Capsule.
      

      

        
"Read and change all your data on all websites" and "Access the page debugger backend"

        

          Capsule saves a PDF and a full copy of the page you capture with Chrome's own print
          and save tools, and Chrome only lets an extension use those through its debugger,
          which it describes this broadly. Capsule uses it on one tab, only when you click
          Capture, hides the page's ads for that moment, and puts the page back and lets go as
          soon as the copies are made. It never changes your data on any site.
        

        
"Proceed with caution: this extension is not trusted by Enhanced Safe Browsing"

        

          You see this only if you have turned on Chrome's Enhanced Safe Browsing. It reflects
          how long the developer has been publishing on the Chrome Web Store, not anything the
          extension does: Google treats new developers this way for their first few months.
          Capsule is open source, so anyone can
          read exactly what it does.
        

        
Later, Chrome may ask about a site

        

          When a record image has to be saved from a site, Capsule asks Chrome for that one site,
          and Chrome shows you the question. Nothing else is asked for at install.
        

        
Optional: the Capsule button on every page, and site downloads

        

          Under Settings in the Capsule popup you can turn on a small Capsule
          button on every page and let Capsule keep the file you download with a site's own
          Download button. Chrome then asks to let Capsule read pages on all sites and see your
          downloads. Capsule looks at downloads only during the few seconds after you start a
          capture. Where Capsule offers a one-click image capture, starting it has Capsule press
          the site's own Download button for that one record; otherwise it never starts one.
        

      

      

        What the extension captures goes only to the Capsule app on your computer. There are no
        accounts and no Capsule servers. If you add your own AI key, the pages you choose to
        have read are sent to Anthropic for reading, and nowhere else.
